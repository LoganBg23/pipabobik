# Аналіз наявних музичних ботів для Twitch

Огляд складено в листопаді 2026 року. Джерела: офіційна документація ботів, форуми OBS і Streamer.bot, r/Twitch, гайди для стрімерів. Посилання наведено в кінці.

## Які боти розглянуто

| Бот | Звідки бере музику | Де працює | Як запускати музику |
|---|---|---|---|
| **Nightbot** | YouTube, SoundCloud | хмара | вкладка-плеєр на сайті Nightbot (AutoDJ) має бути відкрита |
| **StreamElements (Media Request)** | YouTube | хмара | док у SE.Live/OBS |
| **Streamlabs (Media Share)** | YouTube | хмара | віджет Streamlabs |
| **Moobot** | YouTube | хмара | плеєр на сайті |
| **Streamer.bot + YT Music extensions** | YouTube Music Desktop App | локально | стороння десктоп-програма YTM + розширення |
| **Songify / SpotchBot / TwitchTunes** | Spotify | локально / хмара | потрібен Spotify (часто Premium) |

## Систематизовані скарги

### 1. Пошук знаходить не те
- Пошук у StreamElements просто бере **перший результат YouTube**. Через це грають кліпи з інтро, кавери, «8D audio» і відео з балачками.
- Nightbot, Moobot і Streamlabs історично вимагають **вставити посилання**. Глядачам незручно: треба окремо шукати трек на YouTube.
- У гілці розширення YouTube Music для Streamer.bot просять **заздалегідь показувати, що саме знайшлося**, щоб глядач бачив, чи трек правильний.

### 2. Тролінг і довгі відео
- Головна класика: «10 годин Titanic на сопілці». Через це в ботах з'являлися ліміти тривалості, але **за замовчуванням вони часто вимкнені** або налаштовані окремо в кожному сервісі.
- Шумні та «earrape»-ролики. Фільтр Nightbot «лише категорія Музика» дивиться на категорію відео, а не на сам звук.
- Один глядач може забити всю чергу, якщо не задано ліміти на людину й кулдаун.

### 3. Нестабільність і залежність від хмари
- Користувачі скаржаться, що сторінка song request у Nightbot перестала нормально працювати. Після оновлення OBS 27 AutoDJ у браузері OBS **випадково пропускав замовлення**.
- У StreamElements окремі статті підтримки присвячені порожнім або білим докам, крешам SE.Live і зациклюванню оновлень.
- Mix It Up прямо пише, що Song Requests у них **найчастіше блокуються**, бо ліміти API ділять між собою всі користувачі сервісу.
- Розширення YouTube Music для Streamer.bot ламаються після оновлень десктоп-програми YTM. Користувачі пишуть, що на новій версії команди не працюють, а бот відповідає «Could not add song… check the link».
- Розширення Spotify для Streamer.bot іноді помилково каже, що трек «забанений», і замовлення перестають працювати.

### 4. Складне налаштування і незручне керування
- Розширення YTM для Streamer.bot вимагає Client ID, Client Secret, API Key, ID плейлиста, окрему програму YTM Desktop і ручне ввімкнення таймерів. Якщо YTM перемкнулась на автоплейлист, плейлист треба **вручну клацати знову**.
- Nightbot: «команди керування — суцільний біль друкувати» (`!songs skip`, `!songs promote 3`…).
- Щоб показати назву треку на екрані, у Nightbot треба ставити **окрему програму** і брати текстовий файл. Красивого віджета з коробки немає.

### 5. Немає логіну й обмежень YouTube
- Вбудовані через iframe плеєри не відтворюють відео 18+ та відео з вимкненим вбудовуванням. Це загальна проблема музичних ботів на YouTube.
- Немає доступу до власної бібліотеки: не можна просто поставити «мої вподобані» як фонову музику. Резервний плейлист є лише в StreamElements, і він має бути публічним YouTube-плейлистом.

### 6. Черга губиться
- Після перезапуску бота чи наступного стріму черга зникає. У списку побажань до розширення YTM для Streamer.bot окремим пунктом стоїть **«зберігати чергу між стрімами у файл»**.

### 7. Авторські права (DMCA)
- Найчастіша причина, чому стрімери **відмовляються від song request узагалі**: страйки та заглушені записи трансляцій.

## Побажання користувачів (що просять найчастіше)
1. Замовлення **за назвою**, без посилань, і показ того, що саме знайшлося.
2. Ліміти: тривалість, кількість треків на людину, кулдаун.
3. Можливість для глядача **прибрати свій помилковий трек** (у StreamElements є `!wrongsong`).
4. Фоновий плейлист, коли черга порожня.
5. Керування гучністю й пропуск треку для модераторів.
6. Збереження черги між стрімами.
7. Візуальний віджет «зараз грає» і черга.
8. Робота локально, без чужої хмари та її лімітів.

## Як це закрито в pipabobik

| Проблема | Рішення в pipabobik |
|---|---|
| Шукає не те, треба посилання | `!трек назва` шукає в розділі **«Пісні» YouTube Music**: офіційні аудіоверсії, без кліпів, інтро й «10 годин». Посилання YouTube і YT Music теж працюють. Бот одразу відповідає, що саме додав, під яким номером і через скільки хвилин заграє. |
| Тролінг, довгі відео | Ліміт тривалості (7 хв за замовчуванням), ліміт треків на людину, кулдаун, ліміт черги, бан-слова, `!бантрек` для модераторів, опційний фільтр explicit. Усе ввімкнено з коробки. |
| Різна гучність | Нормалізація гучності (EBU R128 `loudnorm`), тож треки звучать рівно. |
| Хмара, вкладки-плеєри, ліміти | Бот і плеєр працюють **локально** на вашому ПК: без вкладок, iframe і спільних з іншими лімітів. Чат читається через офіційний **Twitch EventSub**, а не через застарілий IRC. |
| Залежність від сторонніх програм | Немає YTM Desktop і Spotify. Програвач mpv керується ботом напряму. Пошук іде через ytmusicapi, відтворення через yt-dlp (з JS-рантаймом Deno, як того тепер вимагає YouTube). |
| Складне налаштування | Майстер `python bot.py --setup` питає 4 речі й сам відкриває авторизацію Twitch. Перевірка `--check` показує, що саме не так. |
| Незручні команди | Короткі українські команди. Усі назви можна змінити в `config.toml`. |
| Логін і 18+ | Вхід у **ваш Google-акаунт** через cookies Firefox (або файл cookies.txt) дає треки 18+ та менше капчі «Sign in to confirm you're not a bot». |
| Порожня черга | Коли замовлень немає, грають **ваші вподобані треки з YT Music** (плейлист `LM`) або будь-який вказаний плейлист. |
| Черга губиться | Черга зберігається у `data/queue.json` і відновлюється після перезапуску. |
| Віджет | Власний рожевий віджет із платівкою, що крутиться, обкладинкою треку, прогресом і замовником, а також панель керування для дока OBS. |
| Треба пам'ятати запустити | Lua-скрипт OBS сам запускає бота разом з OBS або з трансляцією, ставить музику на паузу після стріму й закриває бота разом з OBS. |
| DMCA | В інструкції описано, як винести музику на окрему доріжку (Twitch VOD Track): у прямому ефірі її чути, у записі її немає. |

## Що свідомо НЕ зроблено
- **Spotify.** Користувач прямо просив без нього.
- **Хмарний хостинг.** Музика має грати на тому ж ПК, де OBS, тож сервер не потрібен.
- **Обхід DMCA.** Технічно його не існує. Можна лише прибрати музику із записів (див. README).
