# Додаток «!бля»

Виправляє повідомлення, набране не в тій розкладці.

```
Pipa_Fan:   ghbdsn dcsv, zr cghfdb&
Pipa_Fan:   !бля
pipabobik:  ↪ Pipa_Fan хотів гавкнуть: привіт всім, як справи?
```

Бот відповідає реплаєм саме на повідомлення з помилкою, тож у чаті видно, що саме виправлено.

## Як користуватися

| Що написати | Що виправить |
|---|---|
| `!бля` | твоє останнє повідомлення (до 15 хвилин тому) |
| `!бля` відповіддю (Reply) на чуже повідомлення | саме те повідомлення |
| `!бля @нік` | останнє повідомлення цієї людини |
| `!бля ghbdsn` | текст після команди |

`!,kz` теж працює: це `!бля`, набрана в англійській розкладці.

Виправлення працює в обидва боки: `ghbdsn` → `привіт` і `руддщ` → `hello`.

## Що не перекладається

- **Нік автора.** Бот бере його з даних Twitch, а не з тексту. Ще він прибирає `@нік`, який Twitch сам додає на початок відповідей.
- `@згадки`, емоути Twitch, BTTV і 7TV (`KEKW`, `catJAM`), посилання, хештеги, числа.
- Слова, які й так написані правильно. Кожне слово перевіряється окремо, тож у змішаному тексті `ok ghbdsn` → `ok привіт` «ok» лишається як є.

Якщо виправляти нічого, бот так і відповість: «у Pipa_Fan і так усе зрозуміло 🐶».

Від спаму: одна людина може писати `!бля` раз на 10 секунд, увесь чат разом — раз на 3 секунди.

## Як увімкнути

Додаток лежить в окремій папці `addons/blya` і основний код бота не змінює. Щоб його увімкнути, в `pipabobik/app.py` після рядка

```python
        self.chat.handler = self.commands.handle
```

додайте один рядок:

```python
        from addons.blya import install; install(self)  # додаток «!бля»
```

Щоб вимкнути, приберіть цей рядок.

## Перевірка

```
python -m pytest addons/blya
```
